## Avvio simulatore (workaround)

`expo run:ios` scambia simulatore per device fisico (bug devicectl) → richiede code signing inutile. Workaround:

```bash
xcrun simctl install booted ios/build/Build/Products/Debug-iphonesimulator/DrapeDev.app
xcrun simctl launch booted com.drape.app.dev
npx expo start --lan
```
