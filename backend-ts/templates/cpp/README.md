# Student Grade Manager

A modern C++17 application for managing student grades with colored terminal output.

## Build & Run

Using Make:
```bash
make
./grade_manager
```

Using CMake:
```bash
mkdir build && cd build
cmake ..
make
./grade_manager
```

## Features

- Add/remove students and record grades per subject
- View detailed student profiles with per-subject averages
- Class report with subject breakdowns and top performers
- Visual progress bars for grade averages
- Color-coded letter grades (A-F)
- Pre-loaded sample data for demonstration
