# Scientific Calculator CLI

A terminal-based scientific calculator written in C with colored output.

## Build & Run

```bash
make
./calculator
# or
make run
```

## Features

- Basic arithmetic: +, -, *, /, %, ^
- Scientific functions: sin, cos, tan, abs, log10, ln, sqrt, factorial
- Memory operations: store, recall, clear, add
- Calculation history (last 50 entries)
- Colored terminal output with ANSI codes

## Clean

```bash
make clean
```
